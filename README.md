"# LearnJSTSPlaywright4x_Angu

A JavaScript and Playwright learning repository focused on mastering core JavaScript concepts, automation fundamentals, and practical coding exercises.

## Overview

This repository includes:

- JavaScript basics and syntax learning files
- Keywords and identifiers exercises
- Literals and operators practice
- Increment/decrement operator assignments
- Prompt engineering and framework-related learning materials
- Homework and practice files for continued learning

## Project Structure

- `00_chapter_Prompt_Eng/` — prompt engineering and problem statement notes
- `01_chapter_JS_Basics/` — JavaScript fundamentals
- `02_chapter_JS_Keywrods_Identifiers/` — keywords and identifiers
- `03_chapter_JS_Literals/` — literal values and data representation
- `04_chapter_JS_Operators/` — operators and expressions
- `05_chapter_JS_Incre_Decr_Op/` — increment/decrement operator exercises
- `Homework/` — assignments and practice work
- `assets/` — supporting images and resources

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run a JavaScript file from the project root:
   ```bash
   node 01_chapter_JS_Basics/01_HelloWorld.js
   ```
3. To start the default project script:
   ```bash
   npm start
   ```

## Notes

This workspace has been initialized as a Node.js project so the JavaScript exercises can be executed easily from the terminal.

The repository is intended for hands-on learning, practice assignments, and progressively building JavaScript and automation skills.
